# Lane site: open questions (24 Nov decisions)

Nothing was skipped. These choices need a product yes or no; each was built the narrow way and is easy to widen.

1. **Evidence is optional at approval.** An approver sees the attached files before approving, but a head count with no file can still be
   approved. If a file must be required (for all organisations, or per organisation by a setting), say which.
2. **Who attaches.** Exactly the people who may record that head count (Admin, Executive, Project Manager, the crew's field controller with a
   regular account). A field account cannot record a head count today, so it cannot attach either; the brief's "only to head counts they may
   record" is read that way. If field seats should record and attach head counts, that is a change to the head count rule, not to evidence.
3. **Where the file lives.** A project document of the work order's project, filed in a category the person picks (the document register's own
   category and access rules apply). A recorder whose role may not file project documents cannot attach until that role may.
4. **Area rates cover hand-priced lines only.** A line priced from the rate catalogue keeps taking its rate from the catalogue's work
   location, so an area rate is refused on it. If catalogue lines should also vary by area, that is a catalogue change.
5. **Invoices.** Area rates price daily reports (earned value). The contract line's own rate still prices invoices and progress claims.
   If billing should follow the area too, it is a separate money-path item.
6. **A report's own area** (the override) can be set by anyone who may edit the report; the validator sees the rate before validating and
   cannot validate their own report. If only validators should set it, say so.
