## Design and invariants

- `pmo-portal/src/lib/listWorkingSet.ts`, `pmo-portal/src/hooks/useListWorkingSet.ts`, `pmo-portal/src/lib/listReturnContext.ts`, `pmo-portal/src/hooks/useListReturn.ts`, and `pmo-portal/src/hooks/useListSearchWorkingSet.ts` are the authority. Do not duplicate codecs, validate routes locally, or add global return/scroll state.
- Each page supplies its persisted session view through `readProjectView()`, `readPipelineView()`, or `readProcurementView()`, writes a user-selected view with its paired `write*View()`, and renders `workingSet.view`. Only Projects passes `projectsDefaultFilter: roleDefault` and `defaultsReady: effectiveRole !== null`; this prevents a URL write before the Engineer `My Projects` default is known.
- Discrete controls call `setWorkingSet` exactly once per user event. Search uses `useUrlSearchInput(workingSet.q, q => setWorkingSet(ws => ({ ...ws, q })))`; it is never bound directly to `workingSet.q`. A clear action calls the search setter with `''` and makes exactly one `setWorkingSet` update that resets all owned keys in the same snapshot. In particular, URL `filter=My+Projects` remains materialized when an Engineer subsequently types a search.
- Each page calls `useListReturn({ list, contentReady })` with settled, non-placeholder rows/empty state: Projects/Procurement use successful non-pending data; Sales also waits for the lost-deals query. `openRecord()` receives only canonical `/projects/:id` or `/procurement/:id` routes. It captures `main-scroll`, validated list URL, and router state; record tabs are never passed to it.
- Detail BackBars and AppShell’s already-shipped contextual parent breadcrumb use the record owner only: Project routes return to Projects, Procurement routes return to Procurement. A Sales-opened Project carries Sales state only for PipelineLens’s existing quiet Sales Pipeline link, resolved by `listReturnNavigation(location.state, 'sales')`; a direct Project link remains `/sales`. Do not alter `App.tsx`, shared seam files, canonical route shapes, SalesKanban money rows, `src/components/ui/Funnel.tsx`, or `package-lock.json`.
- Per the amended ruling, only existing exact `navigate` assertions on record-open, list-return, archive/delete/fallback, or detail tab-switch paths in these modules may change. Retain the exact destination as the first argument and add the concrete validated `state` assertion; do not use `expect.anything()` and do not weaken any non-navigation assertion. Stop and report any other assertion conflict.
