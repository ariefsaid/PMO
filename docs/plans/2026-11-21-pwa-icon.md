# Installable Web App: Home-Screen Icon Implementation Plan (#2713)

> Spec: `docs/specs/pwa-icon.spec.md`. Parent map: #2516 (contractor field operations).
> Delivers web app manifest, icons, and minimal service worker for home-screen installation on phones.
> Explicitly NO offline caching of data (offline capture scheduled for Q1 2027 per OD-SCOPE-15/16).

## Database / Migration

None required. This feature is purely client/PWA platform assets and service worker registration; no schema, tables, or backend changes.

## Slice 1: Assets & Manifest (AC-PWA-001, AC-PWA-002, AC-PWA-003)

- [ ] Write tests first:
  - `pmo-portal/test/manifest.test.ts`: asserts `public/manifest.webmanifest` exists, is valid JSON, has `name`, `short_name`, `start_url`, `display: standalone`, `theme_color: #4B61DC`, `background_color: #ffffff`, and required icon descriptors.
  - `pmo-portal/test/pwaIndexHtml.test.ts`: asserts `pmo-portal/index.html` references the manifest, favicon, apple-touch-icon, and theme-color meta tag.
- [ ] Add icon assets in `pmo-portal/public/`:
  - `pmo-portal/public/favicon.svg` (crisp vector icon using DESIGN.md primary `#4B61DC` and brand "P")
  - `pmo-portal/public/icon-192.png` (192x192 PNG)
  - `pmo-portal/public/icon-512.png` (512x512 PNG)
  - `pmo-portal/public/icon-192-maskable.png` (192x192 maskable PNG)
  - `pmo-portal/public/icon-512-maskable.png` (512x512 maskable PNG)
  - `pmo-portal/public/apple-touch-icon.png` (180x180 PNG for iOS)
- [ ] Create `pmo-portal/public/manifest.webmanifest`.
- [ ] Update `pmo-portal/index.html` to reference the manifest, favicon, apple-touch-icon, and theme-color.
- [ ] Update `pmo-portal/public/_headers` to ensure `/sw.js` and `/manifest.webmanifest` have appropriate cache control without violating `securityHeaders.test.ts`.

## Slice 2: Minimal Service Worker & Registration (AC-PWA-004, AC-PWA-005, AC-PWA-006)

- [ ] Write tests first:
  - `pmo-portal/test/serviceWorker.test.ts`: asserts `public/sw.js` exists, handles `install`, `activate`, and `fetch`, and strictly contains NO cache writing (`caches.open`, `cache.put`, `cache.add`).
  - `pmo-portal/src/lib/pwa.test.ts`: tests `registerServiceWorker()` for presence/absence of `navigator.serviceWorker`, readyState handling, and error handling.
- [ ] Create `pmo-portal/public/sw.js`:
  - Event listeners: `install` (calls `skipWaiting()`), `activate` (calls `clients.claim()`), `fetch` (pass-through, zero caching).
- [ ] Implement `registerServiceWorker()` in `pmo-portal/src/lib/pwa.ts`.
- [ ] Wire `registerServiceWorker()` in `pmo-portal/index.tsx` alongside `installChunkReloadGuard()`.
