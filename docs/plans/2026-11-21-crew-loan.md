# Crew loan implementation plan (#2704)

Spec: `docs/specs/crew-loan.spec.md`. One builder, test first. Money-adjacent (attendance feeds cost): the DB rule is mutation-checked. Setting added: `organizations.crew_loans_enabled` (default false = unchanged behaviour), Admin switch under Administration, People; the database rules apply regardless.

## Migrations (range 1245 to 1249; rollbacks in `supabase/migrations/rollback/`)
- `1245_crew_loans.sql`: table `crew_loans (id, org_id stamped, worker_id, home_crew_id, host_crew_id, valid_from, valid_to not null, version, created_at)`; check `valid_to >= valid_from`, `home <> host`; `exclude using gist (worker_id with =, daterange(valid_from, valid_to, '[]') with &&)` (AC-LOAN-004); indexes `(worker_id, valid_from)`, `(host_crew_id, valid_from)`; org-stamp trigger; guard trigger `zz_crew_loans_refs` (same-org, live crews, home placement covers the period, hours-locked rule against `attendance_days.approved_at/locked_at/submitted_at`, also on delete via a before-delete trigger, version bump and `log_audit` on update); RLS enabled and forced, select for active members, insert/update `(select crew_can_manage())`, delete Admin only, column grants as `crew_members`; extend `guard_crew_refs` archive check (FR-LOAN-009) through a small separate `before update` trigger on `crews` so 1035 is not rewritten.
- `1246_worker_effective_crew.sql`: `worker_effective_crew(p_worker uuid, p_date date) returns uuid` (security invoker, stable): the loan's host crew if a loan covers the date, else the existing placement resolution (newer placement wins the day). `crew_effective_members(p_crew uuid, p_date date)` returns the (worker, standard_role_id) set for a crew that day: loan-in workers (no standard role) plus placed workers whose effective crew is this crew.
- `1247_work_order_roster_effective.sql`: `create or replace work_order_roster` reading members from `crew_effective_members` (keeps the 1036 signature and JSON shape; `off_rotation` retained; a loaned-in worker has null `standard_role_id` and does not fill a standard role).
- `1248_attendance_record_effective.sql`: `create or replace attendance_record`, copied from 1110 with only the crew-resolution query replaced by `worker_effective_crew` joined to `work_order_crews` (every other line identical; diff is reviewed). Any other reader found by `grep crew_members supabase/migrations` (e.g. timesheet generation) is switched the same way in this migration.
- `1249_crew_loans_setting.sql`: `organizations.crew_loans_enabled boolean not null default false` and Admin-only audited `set_org_crew_loans_enabled(boolean)`. No other reader of `crew_members` routes hours, so 1247 and 1248 are the only reader switches.
- Rollbacks `rollback/1245..1248_*_down.sql`: restore 1036/1110 function bodies, drop functions, trigger, table (header notes loans are lost).
