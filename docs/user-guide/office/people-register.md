# People register

## What this is for

The people register is the workforce list: **everyone who holds expiring documents**, whether
or not they use the app. When someone joins the workforce, add them here so their first
certificate or permit can be recorded — and the expiry warnings start.

A person here is not an app user by default. You can link an app user to a person when it is
true; creating an app account never creates a person, and adding a person never creates an
account.

## Who can do this

- **Add and edit** people: Admin and Project Manager.
- **Archive**: Admin only.
- **Read**: every active member sees the basic fields. Documents on a person follow their own
  access rules (see [document-expiry.md](document-expiry.md)).

## Where to find it

**Administration → People** (Personel). Each row opens the person's record, where their
documents are added.

## Steps

1. Choose **Add person**.
2. Fill in the **Name** (required). Optionally add a **Job title**.
3. Leave the **Person code** blank to have one assigned automatically (P-0001, P-0002, …), or
   type your own code. On **edit**, the code is required.
4. Optionally link the person to an **App user** — pick from the organisation's users. A user
   already linked to another person cannot be linked twice.
5. **Save person**.
6. Open the person's record and add their first document (see
   [document-expiry.md](document-expiry.md)).

## What the result looks like

The register lists **Name**, **Person code**, **Job title** and the linked **App user**. A
person stays in the register until archived; archiving removes them from the register, the
expiry list and the warnings (their past records are kept). Codes of archived people are never
reused by the automatic numbering, but you may type an archived person's code again for a new
person.

## Common problems

| What you see | What to do |
|---|---|
| *That person code is already in use — Choose another code, or leave it blank to have one assigned.* | Codes must be unique among current people. Pick another or let PMO number it. |
| *That user is already linked to another person — Choose a different user, or clear the link.* | One app user maps to one person. Clear the old link first or pick a different user. |
| *Enter the name* | The name is the only required field; fill it in. |
| Add/edit/archive controls are missing | Your role cannot write people (for example, Finance and Engineer cannot). Only an Admin archives. |
| A person is missing from the register | They may have been archived — their record then says so. An Admin can add a new person with the same details. |

## Bahasa Indonesia

# Daftar personel

## Untuk apa ini

Daftar personel adalah senarai tenaga kerja: **semua orang yang memegang dokumen yang bisa
kedaluwarsa**, baik mereka memakai aplikasi atau tidak. Ketika seseorang bergabung dengan
tenaga kerja, tambahkan di sini agar sertifikat atau izin pertamanya dapat dicatat — dan
peringatan kedaluwarsa mulai berjalan.

Personel di sini bukan pengguna aplikasi secara bawaan. Anda dapat menautkan pengguna
aplikasi ke personel bila memang benar; membuat akun aplikasi tidak pernah membuat personel,
dan menambah personel tidak pernah membuat akun.

## Siapa yang dapat melakukannya

- **Menambah dan mengubah** personel: Admin dan Manajer Proyek.
- **Mengarsipkan**: hanya Admin.
- **Membaca**: setiap anggota aktif melihat kolom dasar. Dokumen pada personel mengikuti aturan
  aksesnya sendiri (lihat halaman kedaluwarsa dokumen).

## Di mana menemukannya

**Administrasi → Personel**. Tiap baris membuka catatan personel, tempat dokumennya
ditambahkan.

## Langkah-langkah

1. Pilih **Tambah personel**.
2. Isi **Nama** (wajib). Tambahkan **Jabatan** bila ada.
3. Kosongkan **Kode personel** agar diberikan otomatis (P-0001, P-0002, …), atau ketik kode
   sendiri. Saat **mengubah**, kode wajib diisi.
4. Opsional: tautkan personel ke **Pengguna aplikasi** — pilih dari pengguna organisasi.
   Pengguna yang sudah tertaut ke personel lain tidak dapat ditautkan dua kali.
5. **Simpan personel**.
6. Buka catatan personel dan tambahkan dokumen pertamanya (lihat halaman kedaluwarsa
   dokumen).

## Bagaimana hasilnya

Daftar memuat **Nama**, **Kode personel**, **Jabatan**, dan **Pengguna aplikasi** yang
tertaut. Personel tetap di daftar sampai diarsipkan; pengarsipan mengeluarkannya dari daftar,
daftar kedaluwarsa, dan peringatan (catatan lamanya disimpan). Kode personel yang diarsipkan
tidak pernah dipakai lagi oleh penomoran otomatis, tetapi Anda boleh mengetik kode personel
lama untuk personel baru.

## Masalah umum

| Yang Anda lihat | Yang perlu dilakukan |
|---|---|
| *Kode personel itu sudah dipakai — Pilih kode lain, atau kosongkan agar diberikan otomatis.* | Kode harus unik di antara personel yang aktif. Pilih kode lain atau biarkan PMO menomorinya. |
| *Pengguna itu sudah terhubung ke personel lain — Pilih pengguna lain, atau hapus tautannya.* | Satu pengguna aplikasi untuk satu personel. Lepas tautan lama dulu atau pilih pengguna lain. |
| *Isi nama* | Nama adalah satu-satunya kolom wajib; isilah. |
| Tombol tambah/ubah/arsip tidak ada | Peran Anda tidak boleh menulis personel (misalnya, Keuangan dan Rekayasa tidak bisa). Hanya Admin yang mengarsipkan. |
| Personel tidak ada di daftar | Mungkin sudah diarsipkan — catatannya mengatakannya. Admin dapat menambah personel baru dengan data yang sama. |
