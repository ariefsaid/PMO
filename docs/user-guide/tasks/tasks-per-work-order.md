# Tasks per work order

Tasks on a work order are the site's to-do list: what must be done, who does it, and by when. A
task can require proof of completion — a photo or document — so that "done" on site means there is
evidence. The work order page lists its open tasks, and the project's task board can be filtered
per work order.

**Who can do this:** Admin, Executive and Project Manager create tasks and set the work-order link
and the proof requirement. The assignee moves their task through its statuses and attaches proof.

## Steps

1. Open the project, go to the **Tasks** tab and create a task (name is required; add an assignee,
   dates, priority, description).
2. To tie it to the site work, set **Work order** in the task form. A task can only name a work
   order of its own project; a task with no project cannot name one.
3. Tick **Require proof of completion** when the task must not be closed without evidence.
4. The assignee works the task and keeps its status current: **To do**, **In progress**,
   **Blocked**, **Done**.
5. Before marking it done, the assignee attaches proof in the task's **Proof of completion**
   section: **Add photo** (take or choose a photo) or **Add document** (photo, PDF or Office file,
   up to 10 files, 15 MB each).
6. Mark the task **Done**.

## What the result looks like

- The work order page lists its **Open tasks** (not done) with the assignee and due date, so the
  work order answers "what is still open here?".
- The project's task list can be filtered by work order — all work orders, one work order, or tasks
  with no work order.
- A proof-required task shows its proof count ("1 proof attached."). Done tasks with proof keep
  their proof files.

## Common errors and what to do

- **"Proof required: add a photo or document before this task can be Done."** — attach at least one
  proof file; the Done control unlocks once a file is attached.
- **"A task holds at most 10 proof attachments."** — remove an old file before adding another.
- **"That file is larger than 15 MB."** / **"That file type is not allowed. Use a photo, PDF or
  Office document."** — shrink the file or convert it to an allowed type.
- **You cannot set the work order or the proof flag on your task** — those are structure edits for
  Admin, Executive and Project Manager. The assignee changes only the task's status.
- **You cannot remove a proof file from a done task** — reopen the task first, then remove it.
- **The task cannot move to another project while it names a work order** — clear the work order
  first.

## Bahasa Indonesia

# Tugas per perintah kerja

Tugas pada perintah kerja adalah daftar pekerjaan lokasi: apa yang harus dikerjakan, siapa yang
mengerjakannya, dan sampai kapan. Sebuah tugas dapat mewajibkan bukti penyelesaian — foto atau
dokumen — sehingga "selesai" di lokasi berarti ada buktinya. Halaman perintah kerja memuat daftar
tugas terbukanya, dan papan tugas proyek bisa difilter per perintah kerja.

**Siapa yang bisa melakukannya:** Admin, Eksekutif, dan Manajer Proyek membuat tugas serta
menetapkan tautan perintah kerja dan kewajiban bukti. Yang ditugaskan mengubah status tugasnya dan
melampirkan bukti.

## Langkah-langkah

1. Buka proyek, masuk ke tab **Tugas**, dan buat tugasnya (nama wajib; tambahkan yang ditugaskan,
   tanggal, prioritas, deskripsi).
2. Untuk mengaitkannya dengan pekerjaan lokasi, atur **Perintah kerja** pada formulir tugas.
   Tugas hanya boleh menyebut perintah kerja dari proyeknya sendiri; tugas tanpa proyek tidak
   bisa menyebutkan.
3. Centang **Wajibkan bukti penyelesaian** bila tugas tidak boleh ditutup tanpa bukti.
4. Yang ditugaskan mengerjakan tugasnya dan memperbarui statusnya: **Akan dikerjakan**,
   **Sedang dikerjakan**, **Terhambat**, **Selesai**.
5. Sebelum menandainya selesai, yang ditugaskan melampirkan bukti di bagian **Bukti penyelesaian**
   tugas: **Tambah foto** (ambil atau pilih foto) atau **Tambah dokumen** (foto, PDF, atau berkas
   Office, maksimal 10 berkas, masing-masing 15 MB).
6. Tandai tugas **Selesai**.

## Hasilnya seperti apa

- Halaman perintah kerja memuat **Tugas terbuka**-nya (yang belum selesai) beserta yang
  ditugaskan dan tenggatnya, sehingga perintah kerja menjawab "apa yang masih terbuka di sini?".
- Daftar tugas proyek bisa difilter menurut perintah kerja — semua perintah kerja, satu perintah
  kerja, atau tugas tanpa perintah kerja.
- Tugas yang mewajibkan bukti menampilkan jumlah buktinya ("1 bukti terlampir."). Tugas selesai
  dengan bukti tetap menyimpan berkas buktinya.

## Kesalahan umum dan cara mengatasinya

- **"Bukti wajib: tambahkan foto atau dokumen sebelum tugas ini dapat Selesai."** — lampirkan
  minimal satu berkas bukti; kontrol Selesai terbuka setelah berkas terlampir.
- **"Satu tugas memuat paling banyak 10 lampiran bukti."** — hapus berkas lama sebelum menambah
  yang baru.
- **"Berkas itu lebih besar dari 15 MB."** / **"Jenis berkas tidak diizinkan. Gunakan foto, PDF,
  atau dokumen Office."** — kecilkan berkasnya atau ubah ke jenis yang diizinkan.
- **Anda tidak bisa mengatur perintah kerja atau kewajiban bukti pada tugas Anda** — itu perubahan
  struktur untuk Admin, Eksekutif, dan Manajer Proyek. Yang ditugaskan hanya mengubah status
  tugasnya.
- **Anda tidak bisa menghapus berkas bukti dari tugas yang selesai** — buka kembali tugasnya
  dulu, lalu hapus.
- **Tugas tidak bisa pindah proyek selagi menyebut perintah kerja** — lepas dulu perintah
  kerjanya.
