# PMO user guide

Short, plain-language guides for the people who use PMO day to day at a contract- and
project-based organisation. Each page covers one job: what it is for, who can do it, the
steps, what the result looks like, and what to do when something goes wrong.

## A note on words

This guide uses PMO's generic terms — **work order**, **project**, **client-supplied stock**,
**purchase request**, **material request**, **discipline**, **section**. Your organisation can
rename these words to match its own vocabulary (Admin → Terminology; see
[terminology.md](office/terminology.md)). Where this guide quotes a button or heading, it quotes
the default wording; if your organisation renamed a term, you will see your own word in its place.

## Roles

The app has five roles: **Admin**, **Executive**, **Project Manager**, **Finance** and
**Engineer**. Each guide page lists the roles that can do the job. When a screen says an
action is restricted for your role, the database enforces it — the guide only describes what
you can actually do.

The app runs in English and Bahasa Indonesia. Every guide page has an English section first and
a Bahasa Indonesia section after it, using the app's own Bahasa wording for buttons and
headings.
