# PMO user guide

Step-by-step guides for people using PMO day to day on contract and project work — site supervisors,
crew leaders, store keepers, engineers, project managers and administrators. Each page covers one
job: what it is for, who can do it, the steps, what the result looks like, and common errors.

Every page is written in English first, then in Bahasa Indonesia (`Bahasa Indonesia` section), using
the same wording you see in the app in each language.

## Words this guide uses

The guides use the app's default terms:

- **Project** — the contract or job the work belongs to.
- **Work order** — an ordered package of work inside a project. Site reports, material requests,
  rosters, tasks and stock can all name a work order.
- **Contract item** — a line of the contracted scope, priced in the project's rate catalogue.
- **Discipline** — the trade or specialisation a crew or cost line belongs to.
- **Client-supplied stock** — material given to you by your client at no cost.

Your organisation may have renamed some of these words (for example, calling work orders "service
orders"). An administrator can change these names once for everyone under **Administration →
Terminology** (see [Terminology](office/terminology.md)); the renamed word then replaces the default everywhere in the app, in both languages.
This guide keeps the default wording.

## Roles

The app has five roles: **Admin**, **Executive**, **Project Manager**, **Finance** and
**Engineer**. Each guide page lists the roles that can do the job. When a screen says an
action is restricted for your role, the database enforces it — the guide only describes what
you can actually do.
