# Translation catalogues

`public/locales/<lng>/<ns>.json`, one file per language per feature namespace. Fetched at runtime by
the custom backend in `src/lib/i18n/index.ts` (FR-L10N-043) — **never bundled**, so adding a language
does not grow the `en` bundle by a byte. `public/` is copied verbatim by Vite.

**Only `common` loads at boot (#2097).** `initI18n` passes `ns: ['common']`; a feature catalogue is
fetched when something needs it, by three routes:

1. `useTranslation('<ns>')` — react-i18next loads the namespace its component declares on mount;
2. the route preload rules in `App.tsx` (`PRELOAD_RULES[].namespaces` + `namespacesForPath`) — the
   route's catalogue starts downloading in parallel with its code chunk, so the first paint has it;
3. `parseMissingKeyHandler` — a `t('<ns>:key')` reached through a bare `useTranslation()` (no
   namespace declared) asks for that namespace on demand, and `bindI18n: 'languageChanged loaded'`
   re-renders the subscriber once it lands.

So a NEW screen must do one of: declare its namespace in `useTranslation('<ns>')`, or list it on its
route's preload rule. Both are cheap; neither is optional — an undeclared namespace is a screen that
renders English source strings (or, with no default, its bare key) until the on-demand fetch lands.
When you add a namespace, add its file to `public/locales/<lng>/` AND to `NAMESPACES` in
`src/lib/i18n/index.ts`; the parity guard (`npm run check:guards`) checks the files.

- **`en/`** is the source of truth. It is generated by `i18next-parser` from `t()` / `<Trans>` calls
  and is checked by the en-side completeness gate (FR-L10N-042a): every key the launch-scope source
  references must exist here, and no orphaned key may survive pointing at text nothing renders.
- **`id/` is intentionally EMPTY.** DD-I18N-9 stages the completeness gate: the `id`-side check
  (FR-L10N-042b / AC-L10N-041) ships in the change that POPULATES `id`, not before — with an empty
  catalogue every key is missing by construction, so the check cannot be green on day one. Until then
  a missing key falls back to its English source string, which OD-I18N-1 permits.

⛔ Do not fill `id/` with English "for now". A catalogue that mirrors `en` proves nothing and makes
the stage-2 gate green over untranslated text.
